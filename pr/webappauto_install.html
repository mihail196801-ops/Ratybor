📦 Установка расширения

⚡ Быстрая установка:
Следуйте инструкциям ниже. Весь процесс займёт около 1 минуты.
1

Скачайте установщик

Нажмите кнопку ниже, чтобы скачать автоматический установщик для Windows

2

Запустите установщик

Дважды кликните на скачанный файл install_extension.bat

Установщик сам скачает и подготовит расширение

3

Загрузите в Chrome

Chrome откроется автоматически. Путь к расширению будет скопирован!

Просто:

  1. Включите "Режим разработчика" (справа сверху)
  2. Нажмите "Загрузить распакованное"
  3. Вставьте путь (Ctrl+V)
  4. Нажмите "Выбор папки"
4

Готово!

Расширение установлено! Вернитесь в Telegram для активации.
